# HCode 多 AI 协作：S5b 独立多写任务实施与验收记录

日期：2026-10-12。接续 [S5b 首段记录](./HCode-多AI协作-S5b首段实施与验收记录.md)。本段实现两项独立代码任务并行、逐任务验证/审查/修订，以及候选生命周期和安全采纳。源码尚未提交、推送、打包安装或发布。

## 已交付行为与使用入口

进入项目中的 Claude 或 Codex 会话 → **多 AI 协作** → **隔离代码交付** → 勾选 **启用两个独立写任务并行协作**。

填写总体目标，以及每项任务的目标、Claude/Codex 执行后端和允许修改的准确相对文件路径（每行一个，包含新增测试文件）。确认项目复制范围与检查计划后启动。配置不完整时按钮不可用；已有目录、链接、大小写别名、越界路径或未通过代码准入的后端由宿主拒绝。

当前会话继续作为委派和汇总入口。源 AI 只能派发用户确认的 requestKey；目标、后端与文件范围由宿主冻结。先派发两项，再等待结果。源 AI 未派发的任务显示等待处理，宿主不代替模型擅自派发。

两项任务在派发前复制同一准入基线，但各自拥有工作区、写入租约、冻结版本、检查、报告、独立审查和采纳日志。两个执行/审查回合最多同时运行，整个协作共享原有 12 回合预算，并为必要审查和当前会话汇总保留预算。

通过后分别显示待采纳候选。用户选择具体版本预览、检查冲突并确认采纳；同名文件已有变化时，后采纳的候选停止。没有自动合并、自动采纳、提交或推送。不同文件可逐项采纳，但仍需在原项目复测组合结果。

## 改动边界

| 职责 | 本段实现 |
| --- | --- |
| 任务协议 | `CodeStartOptions.tasks` 首版固定两项；单项配置继续兼容。Delivery 持有自己的 code 状态，Run 负责总体生命周期。 |
| 准入和目录 | `CodeRunService` 校验文件范围、分配同基线独立目录；第二份创建失败时撤回尚未派发的本次目录并释放源会话。 |
| 执行和审查 | 写工具限制确认路径；冻结后再检查实际差异范围。每个候选沿用受限验证、独立审查和有界修订。 |
| 采纳和恢复 | 按实际版本及 workspaceId 路由候选与日志；同原项目写回继续串行，同 Run 的采纳、恢复、接管、清理和续跑互斥。 |
| 人工操作 | 接管、丢弃、重新实现和复审只影响所选任务。已应用且无需恢复时可显式清理可写副本，冻结差异、报告、检查和采纳历史保留。 |
| 重启 | 活动任务停止结果未知时仅锁定相关工作区；不自动续跑。原项目有未完成采纳或待恢复记录时，先恢复再允许 AI 续跑。 |
| 桌面与 IPC | 两项独立配置、任务范围、候选和采纳状态；版本/任务 ID 运行时校验。兼容已有只读、专家及单候选行为。 |

单个任务失败保留另一任务的结果；可以只续跑失败任务。当前采纳仍要求协作完成、对应交付接受、最新候选及同版本必需检查和审查均通过，不开放未通过或整轮未完成的例外采纳。

范围不包括共享目录并发写入、跨候选自动合并、任意数量任务、依赖自动安装、Gemini 代码写入、agy 自主发起，以及设备或插件权限扩展。

## 行为回归与桌面验证

并行专项测试使用外部 CLI 传输替身，文件、业务编排、仓库和检查进程均为真实实现；文件系统失败仅在 IO 边界注入。9 项专项用例覆盖：

- 同名文件独立写入、采纳前原项目不变、首项采纳后另一项冲突、日志按工作区恢复。
- 不同文件逐项采纳及首个历史采纳请求幂等，不读取另一个任务的最新日志。
- 传输失败和范围外实际变更只阻止对应任务；单任务续跑保留其他候选与累计预算。
- 重启未知验证状态锁定相关任务，另一任务仍可接管；不自动执行。
- 应用中途 IO 失败产生真实待恢复日志；重启后阻止 AI 续跑，显式回滚恢复后可复审。
- 采纳与续跑并发请求互斥；已采纳副本清理保留冻结预览，丢弃其他任务不覆盖已应用结果。
- 绝对路径、逃逸、依赖目录、通配符、大小写重复/别名、目录及重复任务 key 在模型调用前拒绝。
- 第二份副本复制失败撤回本次未派发目录，无虚假 Run，源会话释放后可重试。

高风险行为先验证失败再实现。最初并行协议、工作区独立路径和待恢复时续跑限制均由失败测试暴露并补齐；macOS `/var` 到 `/private/var` 的临时目录别名按实际路径注入故障。

## 验收结论与保留限制

S5b 首版两项独立多写任务闭环通过。源码仅覆盖上述协作域与相应协议/UI，普通会话、专家组合和 agy 只读链路保持现有范围。

独立候选的检查基于各自共同原始基线；逐项采纳不能证明组合后的业务兼容，需要用户在原项目复测。同名冲突需要人工整合或以更新后的原项目重新发起协作，不自动解决。自动审查不能保证发现全部缺陷。

本次真实模型验收覆盖 Node 依赖项目和 Claude/Codex 两个写后端；移动设备、Java 构建环境、Gemini 写入和更多任务未获得本段真实验收。运行中整进程 SIGKILL 与显式采纳恢复的既有真实证据见首段记录；本段新增每任务未知状态和待恢复续跑限制的行为验证，没有重复宣称新的原生 SIGKILL 演示。打包安装版尚未验证。
