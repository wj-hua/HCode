# HCode 内置终端设计

以 ZCode 底部终端为参照，使用 HCode 的本地项目和 Electron IPC。每个已打开项目有独立标签组，每个标签拥有独立 PTY；切换项目、会话或收起面板时保留终端和输出。只有项目不再有打开的会话、终端标签被关闭（最后一个标签除外）、shell 退出、窗口关闭或应用退出时回收相应 PTY。最后一个标签的关闭按钮与面板关闭按钮都只收起面板；shell 自行退出时删除标签，最后一个退出时收起面板，下次打开重新创建。

终端首次打开时按项目目录启动登录 shell。提供新建、切换和关闭标签，面板高度可拖拽，⌘J 可切换显示；颜色跟随应用主题。终端输出的 HTTP 链接在系统浏览器打开，使用已有应用打开链接接口。启动失败显示原因。项目名称和标签编号采用 ZCode 规则，编号复用最小空位。侧边终端使用与底部终端独立的标签与 PTY，关闭标签会结束对应进程；收起侧边面板、切换文件预览或工作区时继续运行。HCode 的文件预览和协作面板不是 ZCode 的 side pane 标签容器，入口与跨类型标签的组织方式保留 HCode 现有布局。HCode 暂无 ZCode 的远程工作区和内嵌浏览器。

验证覆盖：多标签独立进程、收起再打开保留输出、不同项目隔离、最后标签关闭、shell 退出、工作区回收、快捷键、拖拽、主题及安装版 PTY。窗口关闭或进程退出时，迟到事件不能重新创建终端。
