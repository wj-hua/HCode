# 专家评审阅读体验实施与验收记录

日期：2026-10-14。分支：`codex/expert-review-conversation-ux`。

## 产品行为

主会话负责阅读，协作面板负责详细核对与操作。

- 研究中：显示评审目标、当前阶段、每位专家的真实研究／互审状态和已完成数量；不估算百分比。暂停、停止后收起运行指示，保留状态与错误。
- 完成后：主会话默认展开评审结论、经互审支持的共识、未解决分歧、未验证事项和局限；不截成三行摘要，不要求进入侧栏才能看结果。
- 阅读：消息与结果使用同一个滚动区域。首次展示完整结果定位到结论开头；用户向上阅读时，后台更新不抢滚动位置。提供“回到最新消息”。
- 证据：每条结论下显示真实专家／冻结版本引用，点击打开对应报告并定位具体结论。原始提示词、原生输出和 JSON 保留在默认收起的详情中。
- 侧栏：专家报告、互审、补充资料、续跑及原生记录继续可用；侧栏内汇总默认收起。
- 布局：分界线支持直接拖拽、左右方向键、Home／End 和双击重置；宽度本机持久化。宽窗口保留消息阅读空间，窄窗口使用可关闭的覆盖面板。
- 字号：会话和协作面板正文统一使用 14px token，辅助信息 12px；标题以字重区分，保持系统字体和阅读行距。原生菜单缩放继续有效。
- 输入框：用量、首输出延迟、输出速度独立成行；权限、模型、速度模式和发送控件根据实际空间换行。

## 工程边界

修改渲染层的阅读与布局，并为宿主现有快照补充只读展示投影。专家报告、权限策略、调度、模型调用、预算及评审规则保持原有状态归属。

`expertConversation` 只投影当前冻结版本及同一报告／审查者的最新尝试，历史失败仍保存在宿主记录中。结果关联必须同时匹配项目与发起会话，缺失原生 id 不视为匹配。

滚动意图由 `useConversationScroll` 管理；冻结报告 IPC 读取由 `useExpertReport` 管理。引用或协作切换时撤销旧请求，旧响应不能覆盖当前证据。读取／复制错误可见。
