# HCode 专家报告弹窗交互验收记录

日期：2026-10-14。开发分支：`codex/expert-list-report-preview`。本记录更新同日上一版「列表尾部报告预览」方案，代码与验收记录一并提交，未推送或合入 main。

## 行为与边界

「查看报告」和主会话结论引用直接打开独立模态弹窗；专家列表不插入报告正文或空预览块。弹窗固定头部展示标题、专家、后端与版本，正文独立滚动。结论引用定位到对应标题并获得焦点；长结论不再居中后将标题滚出视野。

复用项目现有 Radix Dialog，关闭按钮、Esc 与遮罩均可退出，关闭后精确返回原报告按钮或引用。Esc 不穿透到下层协作面板。Tab 焦点限定在弹窗内；窄窗口控制边距，长路径和源码换行；减少动态效果时取消弹窗动画。

改动限于团队目录、报告弹窗、入口焦点与冻结结论的滚动定位。读取状态仍由 `useExpertReport` 管理，数据继续来自冻结产物 IPC。关闭撤销迟到响应；加载和错误在弹窗中可见。专家调度、后端读取修复、权限、冻结报告及业务项目保持原行为。

## 浏览器验证

使用生产页面组件与原真实评审冻结报告；仅替换 Electron IPC，不调用模型、不写入原记录。

- 三份报告分别打开独立 dialog，专家来源与版本正确，弹窗不属于侧栏 DOM，背景处于模态层之下。
- 关闭按钮和 Esc 恢复原报告按钮焦点，三位专家目录仍存在，Esc 不关闭侧栏。
- Tab 进入正文仍处于 dialog；PageDown 只滚动正文，头部保留。
- 主会话引用打开准确结论，选中区块顶部与正文可视区顶部一致，标题可见并获得焦点；关闭返回该引用。
- 延迟读取期间有加载提示；关闭后释放迟到响应，dialog 保持关闭。读取失败展示明确错误，仍可关闭。
- 400×720 视口中，弹窗与正文宽度均为 366px，无横向溢出，关闭控件在视口内。

临时验收页面已移出源码，浏览器页和开发服务已关闭。弹窗依赖 Portal，原有静态服务端渲染的「内联预览正文」测试已移除；团队和未选择时不占位保留静态测试，弹窗交互通过真实浏览器路径验证。
