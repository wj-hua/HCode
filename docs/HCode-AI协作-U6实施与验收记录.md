## 完成行为与改动边界

普通对话、协作执行、专家评审和多模型对比统一使用聊天输入框旁的“工作方式”。协作和专家入口复用当前文字，再预览和确认计划；对比仍为独立回答，不自动互审。旧协作记录入口继续提供查看和恢复，没有新增第二条隐式启动路径。README 改为工作方式、团队、代码交付、恢复和无障碍的中文使用说明。

安装版验收发现并修复以下问题，均保留失败证据并补行为回归：

- 进入对比视图会重挂载输入框，提交确认原先只清理已卸载的输入框。现在消费原 viewId 的已发送内存草稿，并通知当前输入框；发送期间的新编辑保留。
- 对比提交后原项目的持久化草稿仍残留，创建新会话会恢复已发送文字。现在仅在已确认发送且存储内容仍匹配时清理原值；新编辑不被覆盖。
- 历史停止汇总回合借用了最新汇总和全局错误。现在完整 Run 进度展示整体状态，回合卡只展示自身错误，汇总只属于最新成功汇总回合。
- 运行中列表在原生自动标题尚未截短时暴露长宿主首行。现在明确区分临时从首条输入推导的标题与已保存标题，关联业务目标并订阅展示索引变化；即使用户标题具有相同长前缀，用户新增备注仍保留。缺少旧回合元数据时保留原生原文，不猜测迁移身份。

任务和代码交付先展示短目标，完整目标与验收要求可展开。补全侧边栏、新会话、设置、项目文件夹和终端操作的辅助功能名称。原生“视图”菜单增加放大、缩小和恢复默认大小。系统减少动态效果同时约束 Motion、CSS 循环动画和自动平滑滚动；视频背景停止自动播放，状态与颜色反馈仍保留。

业务域限于协作入口兼容、草稿消费、只读展示和无障碍反馈。入口为 Composer、任务视图、侧边栏、运行中列表和原生菜单；状态仍归现有主进程草案 / Run / 采纳服务，界面只持有展示和未发送输入。数据来自原生会话、持久化记录、实际项目文件和安装包，不改冻结报告、审查意见或执行权限。冲突继续由宿主拒绝，界面提供原因与明确确认。未改 Provider 接入协议、预算、自动采纳策略、发布版本或依赖。
